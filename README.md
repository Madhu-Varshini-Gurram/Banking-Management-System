# 🏦 Banking Management System

A Java-based Banking Management System developed to demonstrate core Java programming concepts, Object-Oriented Programming (OOP), exception handling and Collections frameworks.

## 📌 Project Overview

The Banking Management System is a console-based application that simulates basic banking operations. It allows users to manage customer accounts and perform essential banking transactions efficiently.

The project is designed using a modular structure with separate packages for services, exceptions, models and application logic.

## ✨ Features

- **Customer Management:** Create and manage customer accounts.
- **Account Management:** Handle bank account-related operations.
- **Deposit:** Deposit money into an account.
- **Withdrawal:** Withdraw money with balance validation.
- **Balance Inquiry:** Check the available account balance.
- **Fund Transfer:** Transfer money between accounts.
- **Transaction Management:** Maintain transaction details.
- **Exception Handling:** Handle invalid operations and errors.

## ⚙️ How to Run the Project

1. Clone the repository:

```bash
git clone https://github.com/Madhu-Varshini-Gurram/Banking-Management-System.git
```

2. Open the project in IntelliJ IDEA.

3. Configure the required JDK.

4. Configure MySQL and database connectivity if required by the project.

5. Locate `Main.java` inside the `bank` package.

6. Run the `Main` class.
